# Website refinement

This revision treats the original design list as guidance against repetition,
not a blanket ban on color, character, or useful interface details.

## Design

- Cream background, Fraunces headings, original portrait and project layout.
- Teal for primary actions and Godot; purple for the ML demo. Gentle solid
  tints distinguish the two featured projects, while full case studies stay white.
- Restored the pink personal section and its plum text.
- Warm neutral dividers and card borders keep the color from becoming repetitive.
- A few directional/play cues accompany key actions; most links remain text-only.
- Status colors and labels remain where they convey actual project or anime status.
- Clearer copy, consistent spacing, readable secondary text, visible keyboard focus,
  and responsive action wrapping are retained. Hover feedback is immediate.

## Install

Copy this folder into the existing website root. Keep the original resume.html,
anime-data.json, projects/models/, projects/runs/, and projects/runs2/ assets.
Those dependencies were not attached. The original Giphy previews, font service,
and simulation CDN modules require network access. The simulation JS is unchanged.

## Validation

JavaScript syntax, local page/image references, and revised color contrast were
checked. The original resume.html is missing from the attachment set, as are the
data/model dependencies above. Browser rendering was not tested.
